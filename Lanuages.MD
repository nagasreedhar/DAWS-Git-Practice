Programing /scripting lang concepts:
The mistake many people make is learning Python syntax, Java syntax, Go syntax, Bash syntax, etc.

The people who become excellent engineers learn problem-solving concepts first Then syntax.

************  A programming language is just a different way to answer the same questions. ******

Every language you ever learn is basically answering these 8 questions:

1. How do I get data?
2. How do I display data?
3. How do I store data?
4. How do I manipulate data?
5. How do I make decisions?
6. How do I repeat work?
7. How do I reuse logic?
8. How do I talk to files, OS, and other systems?

If you understand those concepts, learning a new language becomes: 

Bash    -> What syntax is used?

Python  -> What syntax is used?

Go      -> What syntax is used?

Java    -> What syntax is used?

Terraform -> What syntax is used?
